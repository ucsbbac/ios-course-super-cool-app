## Project overview

SupperCool is a minimal single-view iOS app built as a course exercise (originally created July 2016, targeting iOS 9.3 / Xcode 7.3-era Swift 2). There is no dependency manager (no CocoaPods `Podfile`, no `Package.swift`, no Carthage) — the project is just the Xcode project plus source files.

## Build, test, and run

There is no CI configuration and no command-line build scripts in this repo. Use `xcodebuild` (or Xcode itself) directly:

```bash
# Build the app for the simulator
xcodebuild -project SupperCool.xcodeproj -scheme SupperCool -sdk iphonesimulator build

# Run all tests (unit + UI)
xcodebuild -project SupperCool.xcodeproj -scheme SupperCool -sdk iphonesimulator test

# Run a single test method
xcodebuild -project SupperCool.xcodeproj -scheme SupperCool -sdk iphonesimulator \
  test -only-testing:SupperCoolTests/SupperCoolTests/testExample
```

Because the project predates Swift's modern argument-label syntax (e.g. `application(application: UIApplication, ...)`), it will only compile with an old Swift toolchain (Swift 2.x under Xcode 7). A current Xcode/Swift toolchain will fail to build it without migrating the syntax — keep this in mind before assuming a build failure is a real bug versus a toolchain mismatch.

## Architecture

The app has a single screen, wired entirely through Interface Builder:

- `SupperCool/AppDelegate.swift` — standard `UIApplicationDelegate` lifecycle stub; no custom app-level logic.
- `SupperCool/Base.lproj/Main.storyboard` — defines the single view controller's layout and wires its `@IBOutlet`/`@IBAction` connections.
- `SupperCool/ViewController.swift` — the entire app's behavior: three `@IBOutlet`s (`coolLogo`, `coolBg`, `uncoolButton`) and one `@IBAction` (`makeMeNotSoUncool`) that toggles their `hidden` state to reveal the "cool" image/background and hide the button.
- `SupperCool/Assets.xcassets` — image assets (`Boom-App`, `bg`, app icon) referenced by the storyboard/view controller.
- `SupperCoolTests/` and `SupperCoolUITests/` — unencumbered XCTest boilerplate (`testExample` stubs) generated by the Xcode template; no real test coverage exists yet.

There are three build targets, matching the three top-level source directories: `SupperCool` (app), `SupperCoolTests` (unit tests, `@testable import SupperCool`), `SupperCoolUITests` (UI tests via `XCUIApplication`). Bundle IDs follow `com.ucsbbac.<TargetName>`.
